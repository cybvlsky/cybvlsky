### [Ember](https://github.com/cybvlsky/Ember)

<a href="https://github.com/cybvlsky/Ember"><img src="https://raw.githubusercontent.com/cybvlsky/Ember/main/docs/hero.webp" width="640" alt="Ember running on a Turing Smart Screen 3.5 inch"></a>

Windows app for the Turing Smart Screen 3.5" USB display. The stock app updates the screen about once a second. Ember sends only the pixels that changed, so gauges, graphs and seconds move at 20 to 30 fps over the same 157 KB/s link. Animated themes, a layout editor, CPU and GPU temperatures.

[Download](https://github.com/cybvlsky/Ember/releases/latest) · [Share a theme](https://github.com/cybvlsky/Ember/discussions/1)

C# · WPF · SkiaSharp · LibreHardwareMonitor
